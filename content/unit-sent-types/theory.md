# Các Loại Câu Theo Mục Đích Nói

## 1. Câu trần thuật (Statements)

Đưa ra thông tin: **S + V + …**

- She works in marketing.

## 2. Câu nghi vấn (Questions)

- **Yes/No**: Do/Does/Did + S + V…?
- **Wh-**: Wh-word + (aux) + S + V…?
- **Question tags**: You are ready, **aren't you**?

## 3. Câu mệnh lệnh (Imperatives)

**V-bare** (không to): Go to bed! / Please sit down.

## 4. Câu cảm thán (Exclamations)

**What + (a/an) + adj + N!** / **How + adj/adv!**

- What a beautiful day!
- How fast he runs!
