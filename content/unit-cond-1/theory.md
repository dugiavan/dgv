# Câu Điều Kiện Loại 1 (First Conditional)

Diễn tả điều kiện **có thể xảy ra** ở hiện tại hoặc tương lai.

## Cấu trúc

`If + S + V(s/es) (Present Simple), S + will/can/must + V-bare`

## Ví dụ

- If it rains, we will stay at home.
- If you study hard, you will pass the exam.

## Lưu ý

- Mệnh đề **If** thường dùng **hiện tại đơn**, không dùng will.
- Mệnh đề chính dùng **will + động từ nguyên mẫu**.

## Từ thay thế If

Unless, provided that, as long as, in case (cùng logic điều kiện).
